# Portfolio Website

A clean, professional one-page portfolio website for Khushi Kumari ready for static deployment.

## Files
- `index.html` — portfolio homepage
- `styles.css` — layout and styling
- `Khushi_Kumari_CV.pdf` — downloadable resume file

## Open locally
1. Open `index.html` in your browser.
2. Or use a live server extension for best results.

## Deploy
1. Push this folder to a GitHub repository.
2. On GitHub, enable Pages from the repository settings and select the `main` branch with the root folder.
3. The site will publish at `https://<your-username>.github.io/<repository-name>/`.

## Notes
- The site is static HTML/CSS only.
- The resume PDF exists as `Khushi Kumari .pdf`; rename it to `Khushi_Kumari_CV.pdf` if you want the download button to work without editing the HTML.
